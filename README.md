## 🎨 الهوية البصرية

- **Primary Teal:** `#009BC5` — اللون الأساسي الفاخر
- **Gold Gradient:** `#D4AF37 → #F27628` — للأزرار الرئيسية وعناصر CTA
- **Pearl Background:** `#FBFCFD` مع Mesh Gradient متحرك
- **Typography:** Cairo (Body) + Amiri (Display)
- **Effects:** Glassmorphism 2.0, Magnetic UI, Shimmer Animations

---

## 📦 ما هو منجز (Phase 1)

| الملف | الوصف |
|---|---|
| `tailwind.config.ts` | نظام التصميم الفاخر (ألوان، animations، gradients، shadows) |
| `app/globals.css` | Mesh Gradient، Glassmorphism، Magnetic CTA، Scrollbar مخصص |
| `app/layout.tsx` | RTL Layout مع Cairo + Amiri، SEO كامل، JSON-LD |
| `lib/mockData.ts` | 20 منتج فاخر عبر 10 فئات + Helpers |
| `next.config.js` | تحسين الصور (AVIF/WebP) من Unsplash + Pexels |
